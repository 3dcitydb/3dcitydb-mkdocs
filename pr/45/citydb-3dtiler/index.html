    3D Tiles citydb-3dtiler overview

    citydb-3dtiler

    citydb-3dtiler turns the city objects stored in a 3DCityDB v5 into 3D Tiles, ready to be streamed to web viewers such as CesiumJS or the 3DCityDB-Web-Map-Client. One command reads the features from the database, colors them, and writes the tileset.

    Testing phase

    citydb-3dtiler is still being tested. Use it with care in production, and please share your feedback on GitHub.

    What it can do¶

    • Create 3D Tiles 1.1 or 1.0 from any data in a 3DCityDB v5
    • Color features by object class or by attribute value, using a simple CSV file
    • Embed feature attributes so they can be queried in the viewer
    • Tile only parts of your data, filtered by type, area, ID, CQL2 or SQL
    • Run in Docker without installing anything else
